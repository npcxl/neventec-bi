## fix: Construct/modal/BoothModal 改为 Tailwind + 清理 CSS 冲突

### 根因
`src/components/modal/BoothModal.css` 中 `.booth-modal__detail` 用了 `position: absolute` + `nth-child` 固定坐标（6字段2列x3行）。当同一页面同时加载 Construct 弹窗（12字段）时，第7-12个字段没有 nth-child 规则，全部叠加。

### 解决方案
将 Construct 弹窗完全改为 Tailwind 布局，类名前缀从 `booth-modal__*` 改为 `construct-*`，彻底避免与 modal/BoothModal.css 冲突。

## fix: 补齐窗口化轮播循环缓冲项 (commit 4541d43)

修改了3个文件，修复窗口化轮播的循环缓冲问题：

### useWindowedCarousel.ts
- **renderCount 修复**: 去掉 `totalCount` 上限限制。`needsScroll=true` 时 `renderCount = Math.min(MAX_DOM_CARDS, viewportCount + 1)`，允许生成大于 totalCount 的 DOM 节点，通过取模实现循环缓冲。
- **visibleItems**: 移除 `idx < items.length` 边界检查，允许 `renderCount > totalCount` 时通过 `(windowStart + i) % totalCount` 取模产生重复图片。
- **1张图片不溢出**: `needsScroll=false` 时 `renderCount = Math.min(totalCount, viewportCount)`，只渲染需要的卡片。
- 移除未使用的 `BUFFER_COUNT` 常量。

### ConstructCarousel.tsx (Construct & Safety)
- **key 修复**: `key` 从 `${item.address}-${realIndex}` 改为 `${slotIndex}-${realIndex}-${item.address}`，避免同一 `realIndex` 在窗口中重复出现时 key 冲突。

## perf: 优化展会概况虚拟列表长期运行性能 (commit 727a5e5)

只修改 `src/components/SeamlessVirtuaList/index.tsx`，LeftSidebar/RightSidebar 无需改动。

### 删除完整 loopData
- 移除 `repeatCount` 和 `loopData`（旧代码 `Array.from({ length: repeatCount }).flatMap(() => data)` 最少复制3份完整数据）。
- 改为窗口渲染：`renderCount = visibleCount + overscan*2 + 2`（不滚动时去掉+2）。
- 通过取模获取真实数据：`realIndex = (windowStart + i) % dataLen`。
- 100/1000/5000条数据时 DOM 行数只与视口+overscan 有关。

### 保持无缝滚动
- `localOffset` 只保留当前行内位移 `0 <= localOffset < itemHeight`。
- 跨行时 `windowStart` 累加，`localOffset` 保留余数，通过 `while` 循环正确处理多行跨越。
- 大 dt 安全兜底：额外 `Math.floor/mod` 处理极端情况。
- key 使用 `${slotIndex}-${realIndex}` 避免循环重复项冲突。

### 降低长期运行负担
- **不每帧 setState**：只在跨行时更新 `windowStart`，且限流到 ~30fps（`SETSTATE_INTERVAL=33ms`）。
- rAF 只操作 `track.style.transform`。
- 3个列表从 60fps 降到 ~30fps setState，减少 React 协调开销。
- track 增加 `willChange: "transform"`。
- 内容不溢出时不启动 rAF。
- `prefers-reduced-motion` 开启时不启动滚动。

### 修复暂停和后台恢复
- 三个独立 ref：`hoverPausedRef`、`visibilityPausedRef`、`reducedMotionRef`。
- `visibilityState !== "visible"` 时暂停，恢复可见时重置 `lastTimeRef` 避免大 dt。
- 鼠标暂停不被 visibility 覆盖。

### 避免无意义重启
- rAF 生命周期只依赖 `needsScroll`，不依赖 `data` 引用。
- 使用 `dataRef`、`renderItemRef`、`itemHeightRef`、`speedRef` 保存最新值。
- 数据轮询更新但长度不变时，不销毁重建动画循环。
- ResizeObserver、matchMedia、visibilitychange、rAF 均在卸载时清理。
- 切换模块 10 次不会产生多条动画循环。

## perf: 完善虚拟列表帧率与边界处理 (commit 48cf0b9)

只修改 `src/components/SeamlessVirtuaList/index.tsx`。

### 删除 while 循环 → O(1)
- `crossed = Math.floor(localOffset / curItemHeight)` + `localOffset = localOffset % curItemHeight`。
- `curItemHeight <= 0` 时安全跳过，禁止死循环。
- 单帧跨越任意多行一次计算完成。

### 真正限制视觉更新频率
- 新增 `lastFrameTimeRef`，transform 写入限流到 ~30fps（33ms）。
- rAF 继续调度，offset 和 crossed 每帧正常累加计算。
- 不足 33ms 时不写 DOM transform，但 crossed 计算不受影响。
- `setWindowStart` 每次 `crossed > 0` 都同步（不节流），保证数据窗口正确。

### 修复空数据后 ResizeObserver 绑定
- 改用 callback ref `setContainerRef`。
- 空数据返回的容器也绑定 callback ref。
- 节点出现时立即 `measureHeight()` + 绑定 ResizeObserver。
- 节点替换或卸载时断开旧 observer。

## fix: 修复虚拟列表跨行闪烁 (commit 7ecd514)

只修改 `src/components/SeamlessVirtuaList/index.tsx`。

### 修复跨行时全部 DOM 重建
- **key 改为 `key={slotIndex}`**：slotIndex 是稳定的槽位编号，windowStart 变化时 React 复用同一 DOM 节点，只更新内部内容。
- 旧 key `${slotIndex}-${realIndex}` 在 windowStart+1 时全部变化，导致整组 Unmount/Mount。

### 保证窗口内容与 transform 同步
- 新增 `crossedRef` 标记当前 tick 是否跨行。
- rAF tick 中跨行时不写 transform（跳过 30fps 节流）。
- 新增 `useLayoutEffect([windowStart])`：在 React commit 后、浏览器 paint 前同步写入 `track.style.transform`，实现内容窗口和位移在同一次绘制完成。
- 跨行后重置 `lastFrameTimeRef=0`，确保下一帧正常节流不受影响。

### 补齐循环尾部缓冲
- `renderCount` 不再被 `dataLen` 限制：`Math.max(visibleCount + 1, Math.min(dataLen, visibleCount + overscan*2 + 2))`。
- 允许通过 `(windowStart + slotIndex) % dataLen` 取模重复数据。
- 10条数据、视口约9.4行时底部不再出现空白。

### 修复空数据测量
- `measureFromNode` 直接使用 callback ref 传入的 node 测量，不再通过 `trackRef.current?.parentElement`。
