## 启动失败 + RightSidebar 崩溃排查

### 1. `npm run dev` 报 `crypto$2.getRandomValues is not a function`
- 根因：当前默认 shell 的 Node 是 **v16.20.2**（已 EOL）。项目装的 Vite 是 **6.4.2**，engines 要求 `^18 || ^20 || >=22`；resolveConfig 阶段调用 `crypto.getRandomValues`，该全局 API 在 Node 19 之前不存在 → 直接启动失败。
- 解决：系统已用 nvm 装有 **Node 24.15.0**，切到它即可：`nvm use 24.15.0 && npm run dev`（端口 7000 返回 200）。
- 约定（重要）：本机跑 dev/build 必须用 **Node ≥18（推荐 20/24 LTS）**。当前默认 node 仍是 16，每次新 shell 需先 `nvm use 24.15.0`。

### 2. `ExhibitionRightSidebar` `RightSidebar.tsx:230` `Cannot read properties of undefined (reading 'length')`
- 根因：`orderItems` 来自 `normalizeOrderCollect(orderCollect)`，原实现直接把接口数组 `as OrderItem[]` 强转；但接口实际返回的字段名**不是 `name`/`num`**（声明只是理想形态），导致部分项的 `name` 为 undefined，`.map(i => i.name.length)` 崩溃。
- 解决：`normalizeOrderCollect` 改为兼容多种字段名（name/type/category... / num/count/value...），缺失时 name 兜底为 "其他"、num 兜底为 0。
- 文件：`src/components/Exhibition/RightSidebar.tsx`
