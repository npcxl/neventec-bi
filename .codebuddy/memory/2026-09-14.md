# 2026-09-14

## 展馆排序修复：支持「数字+字母」馆名（6A馆 / 6B馆）

- 文件：`src/hooks/useHallSorter.ts`
- 现象：`1 2 3 4 5 ... 6A 6B` 顺序错乱，6A/6B 被甩到列表最末尾。
- 原因：`parseHallSortKey` 原先只识别 ①纯数字 ②中文数字 ③纯字母 三类；`6A馆`/`6B馆` 不匹配任何正则 → 落入 `nonSortable` 桶，被追加到末尾并保持接口原始顺序。
- 修复：新增 `mixed` 排序键（正则 `^(\d+)\s*([A-Za-z])\s*号?\s*(馆|展馆|展厅|厅)$`），比较器改为先按主号数值排，同主号时纯数字馆优先、再按字母后缀排；纯字母馆仍整体排在数字类之后。
- 结果顺序：`1号馆 … 5号馆 6号馆 6A馆 6B馆 7号馆 … 10号馆 10A馆 … A馆 B馆`。
- 影响面：`CenterMap` 展馆标签栏 + `HallOverviewMap`（全馆概览卡片）共用该 hook，两处一并生效。
- 备注：`alphaToNum(String(...))` 加了 String() 包装以绕过联合类型收窄问题（ts 2345）。
