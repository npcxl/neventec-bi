请帮我生成一个适配 iPad 端的前端页面方案，整体风格和 PC 端一致，但需要适配触控交互与平板屏幕尺寸。

这是一个展会 / 场馆 / 搭建管理类页面，核心是“自绘平面地图 + 2D/3D切换 + 点击交互 + 状态切换 + 详情下钻”。  
iPad 端的布局要接近 PC 端的大屏看板风格，但操作方式要适合触摸，支持点击、滑动、抽屉展开、分栏切换。

====================
一、整体定位
====================

页面适配 iPad 横屏优先，也要兼容竖屏基础浏览。

整体视觉风格：
- 深色科技感
- 蓝 / 青 / 紫高亮
- 半透明卡片
- 发光边框
- 数据大屏感
- 现代、简洁、高级

页面要体现出“PC端看板风格 + 平板触控交互”的混合特征。
    
====================
二、整体布局结构
====================
     
页面结构建议为：
                  
1. 顶部 Header
2. 左侧模块区 / 概览区
3. 中间主地图区
4. 右侧详情区 / 列表区
5. 底部状态切换区
6. 点击点位后弹出详情抽屉或浮层

如果横屏空间足够，建议采用三栏布局：
- 左侧：概览 / 模块列表 / 筛选
- 中间：自绘平面地图主视图
- 右侧：详情 / 列表 / 告警信息

如果空间不足，右侧区域可以折叠为抽屉，点击点位后从右侧或底部滑出。

====================
三、地图类型说明
====================

这里的“地图”不是高德、百度这种真实地理地图，而是我们自己渲染的场馆平面地图 / 展馆平面图。

地图要求：
- 使用 SVG / Canvas / 图片底图 + 叠加图层 实现
- 支持点位、区域、路线、标签、告警、施工状态
- 支持 2D / 3D 切换
- 支持放大、缩小、拖拽、点击点位
- 所有内容由业务数据驱动
- 不是传统导航地图

地图模式：
1. 2D 模式
   - 平面展示
   - 适合查看位置和状态

2. 3D 模式
   - 基于同一张平面图做立体化展示
   - 可以使用透视、阴影、层级浮起、空间高亮
   - 不是地球地图，也不是卫星地图

====================
四、iPad 端布局建议
====================

建议在 iPad 横屏下使用“左中右”结构：

左侧模块区：
- 项目总览
- 当前状态统计
- 模块切换
- 筛选条件
- 图层开关

中间地图区：
- 自绘平面地图主视图
- 占据页面最大区域
- 支持点位交互
- 顶部可放 2D/3D 切换
- 地图右上角可放图例和筛选按钮

右侧详情区：
- 当前选中点位详情
- 任务列表
- 告警列表
- 施工信息
- 支持 tab 切换

如果宽度不足，右侧详情区可以改成：
- 点击点位后从右侧滑出抽屉
- 或底部半屏抽屉

====================
五、三个核心模块
====================

虽然整体接近 PC 端，但依然要围绕三个模块组织内容：

模块 1：总览
- 展示整体项目状态
- 显示全部点位
- 显示统计数据
- 地图展示全局关键节点

模块 2：施工
- 展示施工中区域
- 只高亮施工相关点位
- 显示进度、任务、负责人

模块 3：告警
- 展示异常点位和待处理事件
- 地图高亮告警区域
- 显示告警列表和处理状态

这三个模块建议放在左侧模块区或顶部切换栏中，切换后地图和右侧详情联动刷新。

====================
六、地图状态切换
====================

地图必须支持进入后切换不同状态，不是静态展示。

状态切换方式：
- 全部
- 正常
- 施工中
- 已完成
- 告警

图层切换方式：
- 点位图层
- 区域图层
- 任务图层
- 告警图层

显示模式切换：
- 2D
- 3D

切换时地图内容要实时联动更新，不跳转页面。

====================
七、点击交互要求
====================

iPad 版本的重点是点击交互，要做得像真正的业务工作台。

点击地图点位：
- 点位高亮
- 其他点位弱化
- 右侧详情区更新
- 如果当前没有展开详情，则自动打开详情抽屉
- 可以继续点击进入更深层详情

点击区域块：
- 地图定位到区域
- 显示该区域内点位
- 右侧展示区域任务 / 告警 / 施工信息

点击列表项：
- 地图自动定位到对应点位
- 点位闪烁高亮
- 详情区同步切换

点击 2D / 3D：
- 同一数据切换不同渲染方式
- 保持当前选中点位和当前筛选状态
- 带过渡动画

点击模块切换：
- 总览 / 施工 / 告警 三个模块切换
- 地图内容和右侧列表同步变化
- 顶部标题和统计数字同步变化

====================
八、右侧详情区结构
====================

右侧详情区建议采用卡片式 + tab 切换结构。

内容包括：
- 当前选中点位名称
- 状态
- 所属区域
- 施工进度
- 告警等级
- 负责人
- 更新时间
- 备注信息

可切换的标签页：
1. 详情
2. 任务
3. 告警
4. 历史记录

右侧详情区要求：
- 信息密度高，但排版要清晰
- 适合平板阅读
- 不要太挤
- 支持滚动
- 支持折叠分组

====================
九、左侧模块区结构
====================

左侧模块区可以作为 iPad 端的控制中心。

内容建议：
- 页面标题
- 项目名称
- 当前时间 / 状态
- 总览统计
- 模块切换按钮
- 状态筛选
- 图层开关
- 搜索入口

左侧区块可以采用：
- 卡片式统计块
- 筛选 chip
- 开关按钮
- 列表式导航

====================
十、底部区域与抽屉
====================

如果需要保留底部区域，可以放：
- 简短状态条
- 图例说明
- 当前选中点位摘要
- 快捷操作按钮

如果点击点位后内容较多：
- 使用右侧抽屉
- 或底部半屏抽屉

抽屉适合展示：
- 点位详情
- 任务详情
- 告警详情
- 一键处理操作

抽屉要求：
- 可拖动展开
- 可收起
- 不遮挡地图核心区域太久
